# CLAUDE.md

Instruções para o Claude Code neste repositório.

## Commits e autoria

Não adicionar atribuição ao Claude nos commits — nada de `Co-Authored-By:
Claude...` nem `Claude-Session:` no corpo da mensagem, e não usar "Claude"
nem `noreply@anthropic.com` como autor/committer. Os commits devem ser
assinados como o autor real do trabalho (o dono do repositório).
